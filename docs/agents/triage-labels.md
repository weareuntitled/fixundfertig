# Triage labels

Verwende für jede kanonische Rolle das zugeordnete GitHub-Label.

| Rolle | GitHub-Label | Bedeutung |
| --- | --- | --- |
| needs-triage | needs-triage | Muss bewertet werden |
| needs-info | needs-info | Wartet auf weitere Informationen |
| ready-for-agent | ready-for-agent | Vollständig beschrieben, bereit für einen Agenten |
| ready-for-human | ready-for-human | Benötigt menschliche Umsetzung |
| wontfix | wontfix | Wird nicht umgesetzt |
