# Domain docs

Dieses Repository verwendet einen gemeinsamen Domain-Kontext.

## Vor der Code-Erkundung

- Lies `CONTEXT.md` im Projektstamm, sofern vorhanden.
- Lies die für das Arbeitsgebiet relevanten Architekturentscheidungen
  unter `docs/adr/`, sofern vorhanden.

Fehlen diese Dokumente, arbeite ohne Hinweis weiter.
Der Skill `domain-modeling` legt sie an, sobald konkrete Begriffe oder
Entscheidungen geklärt sind.

## Ablage

- Gemeinsames Glossar: `CONTEXT.md`
- Architekturentscheidungen: `docs/adr/NNNN-kurztitel.md`

## Begriffe und Entscheidungen anwenden

Nutze die Glossarbegriffe in Issues, Vorschlägen, Code und Tests.
Prüfe bei fehlenden Begriffen, ob ein vorhandener Begriff passt;
halte echte Lücken für `domain-modeling` fest.

Benenne Widersprüche zu bestehenden ADRs ausdrücklich und begründe,
warum die Entscheidung erneut betrachtet werden sollte.
